Things I've built and solved

CASE STUDY

Pairwise Coverage Matrix

Policy settings created 48 possible combinations, too many to run every release. I applied pairwise (all-pairs) design so every pair of parameter values still gets tested at least once, which brought the suite down to 12 cases.

Unblocking Email Verification

The mailbox used by our email-notification tests started getting blocked by Cloudflare, so those checks failed for reasons unrelated to the product. I wrote a new page object for a mail.tm inbox and plugged it into the framework, which brought automated email verification back to 100%.
